# Media Lab reference sources

NetViz 3 always renders its five media studios from built-in SVG/CSS construction and signal graphics. These work without internet access. Each studio also links to a Wikimedia Commons reference collection so students can inspect real hardware photographs, authors, licences, and source histories.

| Studio | Reference collection |
|---|---|
| Twisted-Pair Copper | https://commons.wikimedia.org/wiki/Category:Twisted-pair_ethernet_cables |
| Coaxial Cable | https://commons.wikimedia.org/wiki/Category:Coaxial_cables |
| Optical Fibre | https://commons.wikimedia.org/wiki/Category:Fiber-optic_cables |
| Radio Wireless | https://commons.wikimedia.org/wiki/Category:Wireless_networks |
| Infrared | https://commons.wikimedia.org/wiki/Category:Infrared_communication |

The external links are references, not runtime dependencies. A blocked source or offline computer cannot make the Media Lab blank.
